# BAB — Before, After, Bridge

> Modelo adaptado do **marketing**, excelente para **UX Writing**, geração de **microcopy** e mensagens de contorno de fricção.

| | |
|---|---|
| **Categoria** | Corporativo & Analítico (geral) — aplicado a UX Writing |
| **Melhor para** | Microcopy persuasivo, mensagens de erro/vazio, empty states, textos que movem o usuário à ação |
| **Nível** | Iniciante |

---

## Quando usar

Use o BAB quando o texto precisa **mover o usuário de um estado ruim para um bom**: uma tela de erro, um empty state, um paywall, um call-to-action. A estrutura narrativa (dor → alívio → caminho) é o que torna o microcopy persuasivo sem ser vazio.

## Anatomia

| Componente | O que é | Pergunta-guia |
|---|---|---|
| **B — Before** (Antes) | A dor atual ou estado de frustração do usuário. | Onde o usuário está travado? |
| **A — After** (Depois) | O cenário ideal de resolução e sucesso. | Como fica quando resolve? |
| **B — Bridge** (Ponte) | O caminho de escrita/design que leva do A ao B. | Qual é o próximo passo concreto? |

---

## Template (copie e preencha)

```text
Aja como UX Writer. Escreva [tipo de texto] usando a estrutura Before-After-Bridge.

BEFORE: [Descreva a dor/frustração atual do usuário.]
AFTER: [Descreva o estado ideal após a resolução.]
BRIDGE: [Descreva o caminho — a ação que conecta os dois.]

Formato de saída: [ex.: título + descrição + rótulo de botão.]
```

## Exemplo preenchido — Empty state

```text
Aja como UX Writer. Escreva o texto de um empty state usando Before-After-Bridge.

BEFORE: O usuário abriu a área de "Projetos" e não tem nenhum criado — tela vazia, sem direção.
AFTER: Ele entende que projetos organizam seu trabalho e sente que começar é fácil.
BRIDGE: Um botão claro para criar o primeiro projeto, com uma dica do que ele ganha.

Formato de saída: título (máx. 5 palavras) + descrição (máx. 15 palavras) + rótulo do botão.
```

---

## Dicas rápidas

- O **Bridge** deve virar uma ação concreta na interface (um botão, um link) — não só texto motivacional.
- Combine com [ICE](../01-ux-ui/ICE.md) para gerar várias variações rápidas do mesmo microcopy.
- Evite prometer no **After** algo que o produto não entrega — microcopy honesto sustenta confiança.
