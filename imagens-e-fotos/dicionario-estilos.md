# Dicionário Visual: Estilos & Direção

> Fragmentos de prompt para a **linguagem visual geral** da imagem. Encaixe como camada de estilo na [fórmula](anatomia-do-prompt.md).

| Termo | Efeito | Fragmento de prompt (copiar) |
|---|---|---|
| **Modern Flat Design** | 2D limpo, geometria simples (uso: SaaS / UI) | `modern flat vector design, clean 2D illustration, solid colors` |
| **Claymorphism** | Formas amigáveis 3D em "massinha", bordas foscas | `claymorphism 3D render, soft rounded plasticine shapes` |
| **Glassmorphism** | Vidro jateado translúcido, desfoque de fundo intenso | `glassmorphism interface, frosted glass panel, heavy background blur` |
| **Editorial Noir** | Atmosfera sombria clássica, alto contraste e mistério | `editorial noir photography, moody cinematic contrast` |

## Como escolher

- **Modern Flat Design** → interfaces, ilustração de produto, explicações.
- **Claymorphism** → mascotes, onboarding lúdico, apps amigáveis.
- **Glassmorphism** → UI moderna, dashboards, cartões translúcidos.
- **Editorial Noir** → capas, moda, storytelling dramático.
